# RoboJam: A Modular Framework for Social Robotics

**Ongoing Research Project | 2026–Present**

*Modular software infrastructure for adaptable and reusable social robot interactions.*

## Overview

How can we build social robot applications that are easier to develop, extend, and adapt across different robotic platforms?

RoboJam is an ongoing research project investigating modular, hardware-independent software architectures for socially interactive robots.

The framework explores a separation between high-level interaction capabilities and robot-specific hardware interfaces, with the aim of supporting reusable components, interchangeable implementations, and flexible application development.


## Research Motivation

Developing applications for social robots often requires working with platform-specific hardware, APIs, and control mechanisms. This can make it challenging to reuse interaction logic or experiment with new robotic platforms.

RoboJam explores a modular approach in which interaction capabilities can be developed independently of the underlying robot hardware.


## System Architecture

RoboJam follows a modular, layered architecture designed to separate high-level interaction logic from robot-specific hardware implementations.
